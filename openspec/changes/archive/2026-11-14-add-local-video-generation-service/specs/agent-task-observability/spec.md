# Spec Delta

## Purpose

让 Agent 以有限上下文获取共享任务进度、待处理问题与可执行动作，保证跨 Host 的异常可见性和单任务状态一致，避免大量供应商响应、堆栈或敏感信息污染工具输出。

## ADDED Requirements

### Requirement: 分层任务状态

系统 SHALL 返回任务 ID、阶段、状态版本、更新时间、最后已知远端状态及时间、可靠产物摘要和必要动作；不凭空生成百分比。

#### Scenario: 阶段不同
- **WHEN** 供应商成功但下载尚未就绪
- **THEN** 分别显示生成成功与本地产物状态；不把清理或复制失败伪装为生成失败。

#### Scenario: 读取一致性
- **WHEN** 并发操作正更新同一任务
- **THEN** 单次任务响应字段来自一致状态，版本对应内容，不拼接互相矛盾的阶段和动作。

### Requirement: 持久化非消费式异常名单

系统 SHALL 分页提供状态不明和其他待处理原因，保留 task_id、历史及精简错误；查询不清除其他 Host 的可见性。

#### Scenario: 跨 Host 查看
- **WHEN** A 读取了查询耗尽任务
- **THEN** B 仍能看到同一未解决异常，摘要返回待处理数量及入口，不依赖主动推送。

#### Scenario: 状态已核实
- **WHEN** 原未知任务确认成功并开始下载
- **THEN** 显示远端成功和当前下载问题，不继续声称远端未知；产物就绪后移出未解决名单，失败或取消明确后也移出未知名单。

### Requirement: 稳定游标分页

系统 SHALL 限制页大小，支持状态及原因筛选，以稳定排序和游标返回结果，不承诺跨页快照。

#### Scenario: 翻页时变化
- **WHEN** 遍历中新增任务或任务进出待处理状态
- **THEN** 不打乱既定遍历顺序，新进入结果可从首页重新发现；明确翻完一遍不表示之后没有异常。

### Requirement: 版本化有界等待

系统 SHALL 接受已知版本和有限等待时长，变化已发生则立即返回，超时返回当前状态，不改变后台任务。

#### Scenario: 查询等待间变化
- **WHEN** 任务在查询后、等待开始前改变
- **THEN** 根据已知版本立即返回变化，避免漏掉事件。

#### Scenario: 未变化或取消
- **WHEN** 仅查询时间更新、等待超时或调用取消
- **THEN** 无业务变化不反复唤醒；超时标记等待结束，取消只结束调用，不取消生成。

### Requirement: 精简结构化错误

系统 SHALL 返回稳定错误码、阶段、原因摘要、可重试性、是否需处理、允许动作及诊断 ID；可关联时返回任务 ID。

#### Scenario: 长错误响应
- **WHEN** 供应商返回长堆栈、源码、HTML 或重复错误
- **THEN** 不原样透传，返回必要摘要、次数及时间；提交可能接单等关键语义不得被删掉。

#### Scenario: 响应超限
- **WHEN** 自由文本或列表超出配置限制
- **THEN** 截断文本或分页并明确标识，不截断必要 ID、状态及动作字段，不重复输出长提示词。

### Requirement: 脱敏且不可信的诊断

系统 SHALL 对工具和本地日志脱敏，提供按诊断 ID 查询的有界详情，不提供完整原始日志；供应商文本仅为不可信数据。

#### Scenario: 含敏感信息
- **WHEN** 错误含密钥、授权头或签名 URL
- **THEN** 包括调试输出均脱敏，不通过摘要泄露凭据。

#### Scenario: 包含指令或无法解析
- **WHEN** 上游错误夹带执行命令指令或非预期格式
- **THEN** 不执行指令、不读取额外文件或扩大授权；无法解析时报告解析异常和诊断 ID，不猜原因。

### Requirement: 额度与独立运维状态

系统 SHALL 提供生成额度上限、占用和可用量，以及独立的清理、存储与上游可用状态，不将这些状态混同为生成终态。

#### Scenario: 配置下调或存储故障
- **WHEN** 当前占位高于新上限或存储无法保存新状态
- **THEN** 如实显示占用和零可用额度，或显示存储故障及可靠读取结果可能滞后，不篡改数值或假称健康。


### Requirement: 实扣费用记录

系统 SHALL 记录可关联任务的 data.usage.amount 和 currency，保持数值与币种原义；缺失显示尚未返回而非零，不用预扣、供应商成本或推导公式替代实际响应。

#### Scenario: 最终费用到达
- **WHEN** 收到任务最终结算后的完整金额与币种
- **THEN** 保存并在任务查询中返回实际费用，包括失败退款明确返回的 0；重复查询不累计重复计费、不做隐式币种换算。

#### Scenario: 费用未到达
- **WHEN** 生成成功且可下载但 usage 缺失或金额币种不完整
- **THEN** 继续产物流程，费用记为未完整返回；不因费用缺失判定生成失败或自动重提。后续显式刷新可补记，首期不新增无限费用轮询。

#### Scenario: 两个按量成片模型
- **WHEN** 查询国内或国际 draft-to-video 的费用
- **THEN** 仅按实际响应记录，不推导公式或自行估价；不从输入时长和分辨率推算应付金额。

### Requirement: 有效参数与适用性可见

系统 SHALL 预检及接收摘要提供模型、任务类型、有效时长／分辨率及提示词优化决定与来源；详细参数按需获取，不重复输出长提示词。

#### Scenario: 样片与授权
- **WHEN** 请求 draft=true 或依据共享授权开启优化
- **THEN** 显示有效 480p 及优化状态／来源，让 Agent 在提交前可说明实际请求行为；成片与超分显示优化不适用。

#### Scenario: 原始与统一状态
- **WHEN** 上游返回已确认成功别名
- **THEN** 任务详情可区分原始 SUCCESS/completed 与统一生成成功、产物就绪和费用结算状态。
