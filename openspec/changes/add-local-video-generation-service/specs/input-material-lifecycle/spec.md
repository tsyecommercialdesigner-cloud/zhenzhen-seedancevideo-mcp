# Spec Delta

## Purpose

维护视频任务所需本地输入素材的可靠副本与内容身份，明确 URL 引用的恢复限制，以及任务完成或显式放弃后托管副本的受控删除，避免影响用户原文件和仍需恢复的任务。

## ADDED Requirements

### Requirement: 本地素材一致托管

系统 SHALL 接收任务时保存本地素材副本与内容摘要，完成后不依赖用户原路径继续存在；输入准备阶段不进行素材加工；显式独立超分是另一个付费任务，不属于接收阶段自动加工。

#### Scenario: 原文件改变
- **WHEN** 托管成功后原文件被移动、修改或删除
- **THEN** 已接收任务继续使用固定副本。

#### Scenario: 复制期间变化
- **WHEN** 接收复制期间无法获得一致素材副本
- **THEN** 接收失败并清理临时副本，不确认入队。

### Requirement: URL 引用边界

系统 SHALL 只保存外部 URL 引用而不承诺自动缓存或检测其内容变化，对签名等敏感信息脱敏。

#### Scenario: 引用过期
- **WHEN** 排队期间 URL 失效或供应商无法访问
- **THEN** 报告素材不可用或按提交证据标记结果不明，不擅自替换 URL、不承诺与本地副本相同的恢复保证。

### Requirement: 未提交素材修复

系统 SHALL 派发前发现副本缺失或损坏时停止提交，允许通过版本化操作补回摘要一致的内容；不同内容必须新建任务。

#### Scenario: 同内容补回
- **WHEN** 未提交任务获得与原摘要一致的素材
- **THEN** 修复副本并恢复原排队资格，沿用原标识和顺序，不绕过额度及 API 保护。

#### Scenario: 不同内容或已提交
- **WHEN** Agent 尝试替换为不同素材或修改已提交任务输入
- **THEN** 拒绝替换，不改变原任务意图；已经不依赖输入的查询和下载不被素材缺失阻断。

### Requirement: 立即触发的清理条件

系统 SHALL 在产物就绪、明确生成失败、提交前取消、明确上游取消或显式放弃跟踪／下载后立即触发副本清理，不设保留期；其他未完成、结果不明和待恢复下载保留副本。

#### Scenario: 生成成功未下载
- **WHEN** 远端成功但下载尚未完成或需恢复
- **THEN** 不自动清理，除非 Agent 显式放弃。

#### Scenario: 放弃未知任务
- **WHEN** 任务远端未知但显式放弃已生效
- **THEN** 触发清理，不因结果未知无限保留。

#### Scenario: 清理后再生成
- **WHEN** 已清理任务需要重新生成
- **THEN** 要求重新提供所需本地素材，不偷偷读取原路径；凭 task_id 查询和下载不要求重建输入。

### Requirement: 受控且可恢复的清理

系统 SHALL 先可靠记录清理依据和待办，删除范围限于登记且归属明确的托管副本；独立记录待清理、清理中、已清理及失败状态。

#### Scenario: 越界或链接
- **WHEN** 待删路径越出托管目录、涉及目录链接或归属不明
- **THEN** 停止删除并返回诊断，不跟随链接删除外部文件、用户原文件、视频或任务记录。

#### Scenario: 与读取竞争
- **WHEN** 副本仍被合法上传操作使用
- **THEN** 停止旧操作并结束文件使用后再删除，不并发破坏读取。

#### Scenario: 持久化失败
- **WHEN** 终态或清理待办无法保存
- **THEN** 不执行删除；删除完成但结果保存失败时，恢复检查不存在即可补记完成。

### Requirement: 有限清理重试

系统 SHALL 清理失败有限退避重试，耗尽后显示需要处理并提供显式重试；重启不重置预算，不撤销任务终态。

#### Scenario: 占用或权限错误
- **WHEN** 删除因文件占用或权限失败
- **THEN** 保留精简诊断，预算内重试，耗尽等待显式处理；重试工具只接受已满足清理条件的素材。

#### Scenario: 重启或重复执行
- **WHEN** 存在未完成清理待办或副本已不存在
- **THEN** 补做符合预算的清理，已不存在视为完成，不作为致命错误。


### Requirement: 上游依赖核实边界

系统 SHALL 将下列依赖保持为待核实，取得依据前不宣称支持，且按本规范中不确定或不可用分支处理。

#### Scenario: 接口资料尚未核实
- **WHEN** 相关接口文档或能力证据尚未提供
- **THEN** 以下核实边界继续生效：POST /v1/files/upload 及临时 URL 传递已确认；模型特定大小、通用上传限额适用性、精确有效期判断与上游素材读取时机继续待核实。URL 引用不构成可用性保证。上游明确取消成功的清理分支仅在取消及状态语义核实后启用。

### Requirement: 本地素材上传为临时引用

系统 SHALL 在向供应商提交需要本地素材的任务前，使用 POST /v1/files/upload 将托管副本换成公网可访问 URL；上传使用 Bearer API Key 和 multipart file，不直接发送本地文件路径。

#### Scenario: 上传成功
- **WHEN** 托管图片、音频或超分输入视频需传给供应商
- **THEN** 保存上传返回 URL、文件类型、大小及可用的 expires_in 等信息并替换对应请求素材位置；统一代理、CA 和脱敏规则适用，上传不是生成成功。

#### Scenario: 上传前置失败
- **WHEN** 上传失败且生成请求尚未发送
- **THEN** 报告素材上传阶段错误，停止本次生成派发，不误标已向生成接口提交；上传有限重试，耗尽转待处理。

#### Scenario: 上传格式与模型限制不同
- **WHEN** 上传接口可接收某格式或大小但模型不支持
- **THEN** 仍按模型约束校验，不将上传成功视为生成参数有效；通用文档 50MB 和 24 小时临时 URL 规则记录为文档依据，适用性及响应中的实际有效期需核实。

### Requirement: 临时 URL 与稳定输入身份

系统 SHALL 区分用户提供 URL 与服务从本地副本上传得到的临时引用；保留本地内容摘要作为稳定输入身份，URL 更新不改生成意图。

#### Scenario: 排队后上传链接到期
- **WHEN** 生成尚未发送且服务上传 URL 已知过期，本地副本完整
- **THEN** 以同一副本重新上传并更新引用，不新建生成任务、不改变 request_key；请求规范化不得把更换临时签名判为新素材。

#### Scenario: 已提交结果不明
- **WHEN** 已有上传链接过期但生成请求可能已接单
- **THEN** 不以更新素材链接为由重新提交生成，仍遵守未知结果核对规则。

#### Scenario: 外部链接到期
- **WHEN** 用户自带 URL 过期
- **THEN** 不承诺本地缓存或重新上传恢复，报告素材问题；不把输入 URL 有效期当作产物下载 URL 有效期。

### Requirement: 样片清理与超分素材归属

系统 SHALL 沿用既有清理触发条件，不为将来可能的成片保留已应清理的样片输入；超分仅清理该新任务的托管输入副本。

#### Scenario: 样片就绪
- **WHEN** 480p 样片已完成下载且输入清理条件满足
- **THEN** 立即触发输入清理，保留样片任务 ID、区域、已知完成信息和视频；后来成片引用供应商样片而非重新要求原素材。

#### Scenario: 用生成视频超分
- **WHEN** 某已有服务产物被用作新超分任务输入且超分结束
- **THEN** 只清理超分任务托管副本，不删除原生成视频或用户原文件；不把原产物误登记为可清理输入。
