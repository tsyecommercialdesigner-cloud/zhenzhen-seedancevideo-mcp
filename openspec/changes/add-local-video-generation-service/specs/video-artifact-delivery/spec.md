# Spec Delta

## Purpose

将供应商生成结果转换为可检查和可交付的本地视频产物，区分生成成功、下载完成与工作区交付，定义部分失败恢复及不破坏已有文件的复制规则，并保留产物外部删改的真实状态。

## ADDED Requirements

### Requirement: 按产物确认就绪

系统 SHALL 逐个记录必需产物，只有下载完整且通过基本完整性检查才登记就绪；全部必需产物就绪才报告任务本地产物就绪，不承诺内容质量验收。

#### Scenario: 多产物部分成功
- **WHEN** 部分产物下载成功而其他失败
- **THEN** 保留并允许查询复制成功产物，仅恢复缺失或失败部分，不重新生成。

#### Scenario: 临时或无效文件
- **WHEN** 下载中断、文件为空或明显不完整
- **THEN** 不登记为就绪；断点续传未核实则不承诺，允许重新下载未完成部分。

#### Scenario: 登记失败
- **WHEN** 完整视频已落盘但记录保存失败
- **THEN** 保留文件，不报告就绪、不清理输入；恢复后核对并补登记。

### Requirement: 下载恢复不生成

系统 SHALL 以独立下载额度和有限预算处理下载，耗尽后待处理，显式重试使用新预算并保留历史。

#### Scenario: 预算耗尽
- **WHEN** 生成成功但下载多次失败
- **THEN** 保留 task_id、已有产物和输入素材，提供下载恢复入口，不重新占生成额度。

#### Scenario: 磁盘或权限错误
- **WHEN** 下载目录不可写或磁盘不足
- **THEN** 停止受影响下载，提示修复后重试，不持续无效网络重试。

#### Scenario: 链接过期
- **WHEN** 下载链接失效
- **THEN** 仅有已核实上游刷新能力时重新取链接，否则明确待处理，不重新生成。

### Requirement: 本地交付与默认保留

系统 SHALL 默认保留生成视频，返回产物 ID、绝对路径、大小和可靠元数据及分页清单，不返回视频二进制、Base64 或默认暴露签名 URL。

#### Scenario: 产物查询
- **WHEN** Agent 请求已就绪产物
- **THEN** 返回精简清单；不保证 Host 自动播放，不自动打开文件，不提供删除视频 tools 或自动视频清理。

### Requirement: 显式目标路径复制

系统 SHALL 允许按产物 ID 复制到有权限的本地绝对文件路径，或工作区绝对基准下的相对路径，保留服务原产物；不支持 UNC 交付。

#### Scenario: 相对目标
- **WHEN** Agent 提供工作区绝对路径和相对文件路径
- **THEN** 解析并返回目标绝对路径，创建必要父目录；缺少基准拒绝，不猜后端当前目录。

#### Scenario: 相对路径越界
- **WHEN** .. 或目录链接使目标实际位于工作区外
- **THEN** 拒绝相对路径交付；写到工作区外必须明确指定本地绝对路径。

#### Scenario: 目标为原产物
- **WHEN** 目标实际指向源文件
- **THEN** 返回源目标相同，不执行覆盖。

### Requirement: 复制不破坏既有文件

系统 SHALL 默认不覆盖，只有显式允许覆盖才替换；复制完整并验证后才发布目标，失败保全源文件及已有目标。

#### Scenario: 目标存在或并发创建
- **WHEN** 复制前或发布时发现目标已存在且未允许覆盖
- **THEN** 返回冲突，包括内容相同的目标；协调多 Host 冲突并重新检查，不先截断旧文件。

#### Scenario: 复制中断
- **WHEN** 发生权限、占用、空间错误或调用取消且目标尚未发布
- **THEN** 不报告成功，清理临时文件，保留原文件；生成成功状态不变。

#### Scenario: 发布后响应丢失
- **WHEN** 目标已发布但响应未送达
- **THEN** 不回删目标，重试仍按默认不覆盖处理，不要求额外复制幂等标识。

### Requirement: 外部删改可观察

系统 SHALL 获取产物时检查存在性及基本信息，复制或显式完整性检查时核对摘要；发现异常更新状态版本，保留生成事实，不持续扫描全目录。

#### Scenario: 文件缺失或变更
- **WHEN** 已登记视频被外部移动、删除或修改
- **THEN** 标记本地产物缺失或完整性异常，不自动重新下载；其他正常产物仍可用。

#### Scenario: 显式恢复异常文件
- **WHEN** Agent 请求原任务下载恢复
- **THEN** 仅依赖原 task_id 和产物信息，不要求已清理输入；目标异常文件仍存在则显式允许覆盖才替换。

#### Scenario: 交付副本改变
- **WHEN** 用户修改工作区复制副本
- **THEN** 不影响原产物记录，不跟踪该副本或用它自动恢复服务原文件。


### Requirement: 上游依赖核实边界

系统 SHALL 将下列依赖保持为待核实，取得依据前不宣称支持，且按本规范中不确定或不可用分支处理。

#### Scenario: 接口资料尚未核实
- **WHEN** 相关接口文档或能力证据尚未提供
- **THEN** 以下核实边界继续生效：必需产物集合、尾帧 URL 层级、校验信息、下载鉴权、链接有效期和刷新、重定向及续传能力待核实。两个成片模型已声明 mp4/mov，默认封装格式未明确；不得据此认定所有模型都支持 mov。未取得依据时不承诺永久恢复或断点续传；已知生成成功不等于本地文件必然可恢复。

### Requirement: 分辨率模式与产物类型不混淆

系统 SHALL 按任务实际类型保存样片、成片或超分输出及其原始格式，不自动转码或因费用未知阻止下载；原生档和模型超分档的标识保留。

#### Scenario: 样片与成片
- **WHEN** 取得 480p 样片或 native1080p 成片产物
- **THEN** 分别登记到各自任务，后续成片不替换样片文件；成片请求 mp4/mov 时按真实响应及文件检查登记，不仅改扩展名。

#### Scenario: 尾帧未明确
- **WHEN** 请求或继承 return_last_frame 但未获得明确尾帧产物结构
- **THEN** 不编造图片路径、不将未核实尾帧列为已下载；必需与附加产物分类继续待核实，不凭空阻塞或宣称满足尾帧请求。

#### Scenario: 独立超分完成
- **WHEN** 超分得到可下载结果
- **THEN** 按统一完整性、保留和复制规则交付，不覆盖输入视频，不自动开启下一次超分。
