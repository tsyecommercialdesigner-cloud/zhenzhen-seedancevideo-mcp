# Spec Delta

## Purpose

为同一用户的共享视频任务后端提供一致且可解释的配置来源，固定任务输出位置并明确网络与供应商连接身份的变化边界，使多个 Host 不会静默覆盖配置或错误接管旧任务。

## ADDED Requirements

### Requirement: 统一配置与优先级

系统 SHALL 启动时读取后端有效环境变量、固定用户配置位置的 .env 和默认值，按此顺序优先；支持进程级变量及继承的用户级变量，运行环境配置重启生效；提示词优化授权偏好属于独立业务状态，不受重启生效限制。

#### Scenario: 不同项目接入
- **WHEN** Host 工作目录不同但未显式配置冲突项
- **THEN** 使用同一后端配置，.env 不随项目目录改变。

#### Scenario: 运行中编辑
- **WHEN** 用户修改 .env 或用户环境
- **THEN** 当前后端不热更新，新配置等待重启生效。

### Requirement: 统一 API 密钥配置名称

系统 SHALL 使用 ZHENZHEN_SEEDANCE_API_KEY 作为 .env、进程级环境变量和继承的用户级环境变量中的唯一 API 密钥配置名称，沿用统一优先级、重启生效及敏感配置保护规则。

#### Scenario: 指定名称加载
- **WHEN** 用户在支持的配置来源中设置 ZHENZHEN_SEEDANCE_API_KEY
- **THEN** 服务按既定优先级读取并用于供应商 Bearer 鉴权，不在任务、工具响应或日志中回显密钥。

#### Scenario: 通用示例变量名
- **WHEN** 用户只设置文档示例中的 API_KEY 或其他未声明别名
- **THEN** 不静默作为本服务凭据使用，明确提示应设置 ZHENZHEN_SEEDANCE_API_KEY，不暴露已有环境变量内容。

### Requirement: 冲突仅拒绝新接入方

系统 SHALL 新 Host 显式值与后端不同时明确拒绝该接入，不覆盖现有配置、不启动独立后端；未指定值不算冲突。

#### Scenario: 输出或额度冲突
- **WHEN** B 显式配置与 A 所连后端不同
- **THEN** B 收到冲突项及建议，A 和既有任务不受影响。

#### Scenario: 敏感配置冲突
- **WHEN** 凭据等敏感值不一致
- **THEN** 只显示配置项及不一致，不回显值或可推断凭据的摘要。

### Requirement: 按接收时固定输出目录

系统 SHALL 允许环境变量或 .env 显式指定视频目录，按任务接收时保存；任务库及托管素材位置独立于视频目录，不自动迁移旧任务。

#### Scenario: 新旧任务分流
- **WHEN** 由 D 目录改为 E 目录并重启
- **THEN** 新任务使用 E，旧排队任务、重试下载和相同 request_key 找回仍使用 D。

#### Scenario: 旧目录不可用
- **WHEN** 旧磁盘离线或权限不足
- **THEN** 旧任务报告存储错误，不静默改址；新目录可用的独立任务不因此停止。

### Requirement: 统一代理及可信证书

系统 SHALL 对提交、轮询、素材上传和下载应用显式代理、绕过规则及自定义可信 CA；默认直连和证书验证，不自动读取系统代理或 PAC。

#### Scenario: 网络配置无效
- **WHEN** 代理格式或 CA 配置本身无效
- **THEN** 初始化明确失败，不忽略配置或换默认路径。

#### Scenario: 代理或证书故障
- **WHEN** 代理不可达或证书验证失败
- **THEN** 返回脱敏错误，不绕过代理、不关闭验证；仅显式匹配绕过规则才直连，本地可独立操作仍可用。

#### Scenario: 下载重定向
- **WHEN** 产物请求跳转至其他域名
- **THEN** 继续遵循网络策略，不将 API 鉴权头自动跨域转发。

#### Scenario: 网络恢复
- **WHEN** 故障恢复或修复配置后重启
- **THEN** 尚有预算的操作按原计划继续，已待处理或预算耗尽的操作等待显式恢复，历史不重置。

### Requirement: 供应商连接身份保护

系统 SHALL 保存非敏感连接身份、api_id 和必要接口版本而不在任务中保存密钥；仅身份兼容时用当前凭据接续旧任务。

#### Scenario: 同账号换钥
- **WHEN** 凭据更新且可核实仍为同一兼容连接身份
- **THEN** 重启后可继续旧任务，不保留旧密钥作为任务数据。

#### Scenario: 跨账号或端点
- **WHEN** 新账号、区域或基础地址无法确认兼容旧任务
- **THEN** 旧任务保持占位并标记配置不匹配，不盲目查询或重提；本地产物复制仍可用，新任务记录新身份且受同一额度限制。

#### Scenario: 恢复旧配置
- **WHEN** 切回兼容配置但旧任务已待处理
- **THEN** 仍需显式恢复，不重置历史预算；首期不并行配置多个供应商账号。

### Requirement: 配置限制可观察

系统 SHALL 提供可配置队列及素材上限、并发、请求和等待时限、跟踪期限、重试预算及退出时限；拒绝无效取值，具体默认值由后续设计确定。

#### Scenario: 配置期限
- **WHEN** 用户显式关闭生成跟踪期限限制或设置有效期限
- **THEN** 按配置执行且明确显示有效策略；单次请求和工具等待仍有界，不把无限跟踪解释为无限重试。


### Requirement: 上游依赖核实边界

系统 SHALL 将下列依赖保持为待核实，取得依据前不宣称支持，且按本规范中不确定或不可用分支处理。

#### Scenario: 接口资料尚未核实
- **WHEN** 相关接口文档或能力证据尚未提供
- **THEN** 以下核实边界继续生效：同账号识别、区域／端点身份核验及产物下载鉴权待核实；素材上传端点和 Bearer API Key 鉴权已确认；无核验依据时不把 Key 字符串变化等同换账号，也不保证旧任务可接续。代理与 CA 是本地行为要求，指定依赖组合的实现兼容性仍需后续核实。

### Requirement: 共享持久优化授权偏好

系统 SHALL 提供查询、明确设置和撤销提示词优化总是允许的工具操作，同一 Windows 用户跨 Host 共享并跨重启保存；初始无授权，未经用户明确允许不得设置。

#### Scenario: 跨 Host 使用
- **WHEN** 用户通过 A 授予总是允许后 B 提交适用新任务
- **THEN** B 可查询共享授权并采用 true，仍允许单次显式 false；重启后授权保留。

#### Scenario: 即时撤销
- **WHEN** 任一 Host 根据用户明确要求撤销总是允许
- **THEN** 可靠持久化后对随后接收的新任务立即生效，不要求重启，不改变已接收任务快照，也不阻止新的单次明确允许。

#### Scenario: 授权写入失败或竞争
- **WHEN** 偏好更新无法保存或与任务接收并发
- **THEN** 不报告偏好更新成功；接收使用一个一致且已持久化的授权状态并记录依据，不把失败更新当作授权。
