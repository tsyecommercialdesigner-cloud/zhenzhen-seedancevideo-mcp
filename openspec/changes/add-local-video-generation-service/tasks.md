# Tasks

本清单依据已批准的 proposal、八份 specs 和 design 拆分；所有复选框均为未来工作，本轮只创建清单。实施须后续明确 apply 请求。规划产物齐全不代表实现、供应商契约核实或真实验收完成。

执行约定：每项随交付记录实际命令、退出结果、证据位置及未验证事项；失败或缺证据不得勾选，后续发现缺陷需重新打开对应任务。下面的测试命令是待建立的目标命令，不是本轮已运行的验证。测试与文档随所属组交付，末组仅做跨模块集成和验收。

依赖顺序：第 1 组建立契约证据与阻塞台账，可与不依赖上游的第 2–7 组并行推进；第 8 组的真实协议实现依赖对应契约证据，第 9–12 组可先用明确标注的合成适配器隔离验证。第 13 组真实闭环必须先满足对应接口证据和费用授权条件。实现已批准的保守回退不等于核实上游支持；资料若改变已批准范围或技术方案，先修订受影响规划。
