# shared-local-runtime Specification

## Purpose

为同一 Windows 用户的多个 Agent Host 提供通过 stdio 接入的共享本地运行环境，明确后端唯一性、连接存活、退出与恢复行为，使任务不依赖创建它的 Host 持续在线。

## Requirements

### Requirement: 共享 stdio 接入

系统 SHALL 允许同一 Windows 用户的多个 Host 通过各自 stdio 连接共享任务、队列及产物，不按项目隔离权限；首期仅正式支持 Windows 本地运行。

#### Scenario: 跨 Host 接续
- **WHEN** A 已接收任务且 B 接入同一后端
- **THEN** B 能查询和管理同一任务并交付产物；A 退出但 B 在线时后台继续执行，不重复提交。

### Requirement: 唯一调度所有权

系统 SHALL 保证同一共享任务库最多一个后端拥有调度权限；仅确认旧后端退出后允许接管，不自动强杀存活后端。

#### Scenario: 同时启动
- **WHEN** 多个 Host 同时启动或在后端崩溃后同时恢复
- **THEN** 它们协调连接同一有调度权限的后端，恢复尝试有退避与上限。

#### Scenario: 存活但无响应
- **WHEN** 无法确认旧后端退出
- **THEN** 返回后端不可用诊断，不启动第二个调度后端；不能仅凭残留文件或进程 ID 判断实例身份。

### Requirement: 连接失效与有限退出

系统 SHALL 回收失效连接；最后一个 Host 断开后暂停新生成派发，经过配置宽限期和有限收尾时间后退出。

#### Scenario: 宽限期重连
- **WHEN** 最后一个 Host 断开后在宽限期内有 Host 重连
- **THEN** 取消退出计时并恢复调度；宽限期内已有轮询和下载可继续。

#### Scenario: 无连接退出
- **WHEN** 宽限期结束仍无 Host 在线
- **THEN** 不再发起新网络操作，在有限收尾时间内保存状态并退出；提交不明、下载中断按恢复规范处理。

#### Scenario: 强制结束 Host
- **WHEN** Host 或接入进程被强制结束
- **THEN** 连接最终被识别为失效，不永久保留虚假在线计数；是否退出取决于其他有效连接。

### Requirement: 健康信息分层

系统 SHALL 区分本地就绪与上游可用；本地就绪要求配置、存储和调度可用，不通过付费生成验证可用性。

#### Scenario: 上游不可达
- **WHEN** 后端本地就绪但供应商不可访问
- **THEN** 仍允许可靠的本地查询和已有产物复制；健康信息显示最近已知连接情况，未验证则显示未知。

#### Scenario: 初始化失败
- **WHEN** 配置无效或任务库不可读、损坏
- **THEN** 不接收或派发生成任务，返回诊断，不创建空库或退回内存伪装正常启动。

### Requirement: 版本兼容与非破坏启动

系统 SHALL 检查接入协议及任务库格式兼容性，不在普通启动期间隐式执行破坏性迁移。

#### Scenario: 接入不兼容
- **WHEN** 新接入进程无法兼容当前后端
- **THEN** 拒绝该连接并提示正常退出后升级，不强制影响已有 Host、不另起后端。

#### Scenario: 数据格式过新
- **WHEN** 旧程序读取较新任务库
- **THEN** 拒绝调度，不降级改写；需要迁移时要求独立备份、迁移和验证流程。

### Requirement: 可区分的交付验收证据

系统 SHALL 提供 Windows 安装、运行、stdio 接入及故障处理说明，并分别记录隔离测试、多客户端集成、实际 Host 接入和真实 API 闭环的验收状态。

#### Scenario: 未做真实验证
- **WHEN** 仅隔离或模拟客户端测试已通过
- **THEN** 不得宣称实际 Host 或供应商验收通过；每个正式 API 的真实生成、查询、下载和交付结果单独记录，未执行标为未验证。


### Requirement: 模型与工具验收区分

系统 SHALL 在交付说明中区分模型契约覆盖与运行实测，记录 26 个 Seedance 模型、独立超分及提示词优化授权的验证范围，不因共享端点而宣称全部能力已验证。

#### Scenario: 契约已整理但未运行
- **WHEN** 模型参数来自已提供页面而没有实际接口调用
- **THEN** 标为文档契约已整理、真实接口未验证；隔离测试覆盖模型差异及授权，真实调用次数、素材和费用范围另行确定。
